Use the `growth-marketer` subagent.

Write the piece named after `/launch-copy`: landing, post or outreach. If none was named, write all three.

Ground every claim in `docs/requirements.md` and the actual code. Before you write, list the three features you verified exist. If a claim cannot be traced to something real, cut it rather than softening it.

- **landing** - headline, subhead, three benefit blocks each tied to a named feature, one honest limitation stated plainly, one call to action.
- **post** - 120 to 180 words, first person, opens with the problem, includes one concrete detail that proves the thing is real.
- **outreach** - 60 words maximum, one specific reason for this recipient, one clear ask.

End with the one sentence you were least comfortable writing, and say why.
